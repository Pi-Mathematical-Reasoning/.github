The `Pi-Mathematical-Reasoning` organization's profile repository. It is part
of [Pi](https://github.com/Pi-Mathematical-Reasoning/pi).

- [`profile/README.md`](profile/README.md) is the page
  [github.com/Pi-Mathematical-Reasoning](https://github.com/Pi-Mathematical-Reasoning)
  shows: what Pi is, how it works, and every repository and GitHub App in the
  organization. Update it when a repository or an App is added or retired.
- Because this is the organization's public `.github` repository, GitHub uses
  its community health files (`CONTRIBUTING.md`, the pull request template
  and the issue forms in `.github/`) as defaults for any organization
  repository that has none of its own. Every Pi repository ships its own, as
  the conventions require.

The banner, and the header every Pi README opens with, come from
[`pi-branding`](https://github.com/Pi-Mathematical-Reasoning/pi-branding#readme-headers).

Contribution rules are in [CONTRIBUTING.md](CONTRIBUTING.md); the rules for
coding agents are in [AGENTS.md](AGENTS.md).
